# NicheCast

AI social media studio: four content engines (Faceless Studio, Marketing Studio, Creator Studio, Image Studio) that generate video/images — choose between Kling, Seedance, Veo 3.1, Nano Banana Pro and more — then auto-post everywhere. Every post is AI-generated by design, no manual bulk-upload path. Spend is metered with an in-app credits system, and includes a custom pronunciation dictionary for Cameroonian/African names plus an in-app AI assistant.

## Requirements

- Node.js 18+ (nodejs.org)
- **FFmpeg** — needed for video generation. On Mac: `brew install ffmpeg`

## Run it

```bash
npm install
cp .env.example .env.local
npm run dev        # app at http://localhost:3000
npm run worker     # 2nd terminal — renders videos + publishes due posts
```

Everything works with **zero API keys** (mock mode): silent voice track, generated gradient/slideshow visuals, template scripts, simulated posting. Add keys one by one in `.env.local` to go real. ## The four studios

**Faceless Studio** (`/dashboard/video`) — niche → trend research → AI script → voice-over (cloned voice if you've added one, else OpenAI TTS) → stock/AI visuals → burned-in subtitles → thumbnail → SEO pack → schedule. Up to 2 minutes. Choose **Generate & Post** or **Generate & Download only** per video. Billed against your plan's monthly video count, not credits.

**Marketing Studio** (`/dashboard/ads`) — real AI video ads via fal.ai, with a model picker (**Kling** — balanced, **Seedance** — fastest/cheapest, **Veo 3.1** — premium quality). Three modes: standalone **product ad** from photos + a visual template gallery (click a sample thumbnail to use its style), **property/restaurant tour** (upload each room's photo, they're individually animated then stitched into one walkthrough), and **"make one like this"** (paste a reference video link, get an AI-video prompt inspired by its style, not a copy). Resolution 480p/720p/1080p and duration up to 30s, with the credit cost shown live before you generate.

**Creator Studio** (`/dashboard/creator`) — upload a photo once to create a reusable **Character** (digital avatar), then generate that character in different scenarios (office desk, remote-work setup, walking down a street, etc. — pick a visual sample or write your own) with the same model picker as Marketing Studio. The same Character can be reused across future generations, including Marketing Studio ads. Note: this is photo-guided AI video generation, not lip-synced talking-avatar speech — that's a separate, pricier integration (HeyGen/D-ID-style) not built yet.

**Image Studio** (`/dashboard/image`) — AI image generation with a model picker (**Nano Banana Pro** — Google, highest fidelity, **Seedream** — ByteDance, fast/cheap, **Flux Pro** — general purpose). Text-to-image, or upload a reference photo to edit/restyle it instead of generating from scratch. Useful for product shots, ad stills, or one-off graphics.

All four studios render in the background via the worker; pages show live per-step progress. Visual template/scenario/model pickers show a card grid with a sample thumbnail per option (Higgsfield-style) instead of a plain dropdown — currently styled gradient placeholders, since real sample clips need actual generated output first; swap in real thumbnails once you've generated a few.

## Connecting social accounts (fully embedded)

Accounts page has a "Connect [platform]" button per platform — clicking it redirects straight to that
platform's own OAuth login (via Outstand), then back into the app with the account saved automatically.
Users never have to visit Outstand's dashboard or copy an ID by hand. This needs a one-time setup: create
an Outstand account, set `OUTSTAND_API_KEY` + `OUTSTAND_ORG_ID`, and add `{APP_URL}/api/accounts/callback`
as an allowed redirect URI in Outstand's dashboard settings. Bluesky (app password, no OAuth) and other
providers/mock-mode testing fall back to a manual-entry form, collapsed under "Manual entry" on the same page.

## Credits system

Marketing Studio, Creator Studio and Image Studio spend **credits** instead of showing a raw dollar cost —
a resale-friendly abstraction so customers never see your underlying fal.ai bill. The balance shows in the
sidebar (top, "💰 N credits") and on every Generate button before you commit.

Conversion: `lib/credits.js` sets `CREDITS_PER_DOLLAR_OF_COST = 50` (1 credit ≈ $0.02 of real generation
cost) — derived from a Studio-tier example of $30 → 500 credits (~3x markup). An 8s 720p Kling video costs
~$0.80 in real fal.ai spend → 40 credits, which is the reference "typical generation" figure. Cost scales
with **model choice** (Seedance is cheapest, Veo 3.1 is priciest), **resolution**, and **duration** — exactly
as you'd expect from watching the live cost update as you change those fields.

Plan credit grants (`PLAN_CREDITS` in `lib/credits.js`, roughly proportional to plan price, with
Studio/Autopilot rounded up to comfortably cover their advertised video-count promise):

| Plan | Credits/mo | Covers roughly |
|---|---|---|
| Trial | 100 (one-time) | ~2 short generations to try it |
| Publisher | 480 | occasional Image Studio use |
| Creator | 1,650 | ~40 videos/mo at a 720p/8s mix |
| Autopilot | 1,700 | 93 auto-generated 480p/8s videos/mo |
| Studio | 2,500 | ~60 videos/mo at a 720p/8s mix |

Credits are granted automatically on signup (trial) and whenever you manually set a plan — see **Plans &
payments** below. If a queued generation fails during rendering, its credits are automatically refunded.
There's no top-up/checkout flow wired yet (no Paddle webhooks), so "Top up" in the sidebar currently links
to the Billing page rather than a real purchase flow — add that once Paddle is wired.

## Pronunciation dictionary

Accounts page has a **Pronunciation Dictionary** section: define how a Cameroonian/African name or word
should sound phonetically (e.g. "Ébolowa" → "Eh-boh-loh-vah"), and it's swapped in automatically right
before any voice-over is generated (Faceless Studio), whether using a cloned ElevenLabs voice or OpenAI TTS.
On-screen subtitles keep the original spelling — only the spoken audio uses the phonetic version. This is a
lighter-weight fix than voice cloning: no new recording needed, just a word list per user
(`lib/pronunciation.js`, applied in `lib/video/tts.js`).

## AI content disclosure

TikTok/Meta now suppress reach on undisclosed AI-generated video. Every post — all of them are AI-generated now that Bulk Upload is removed — is flagged `ai_generated=1` and passed to the posting provider as a platform-native AI-disclosure field.

## AI assistant

A chat widget (bottom-right, all dashboard pages) answers "how do I..." questions about the app and can write ready-to-paste prompts for any studio. Runs on `ANTHROPIC_API_KEY`; without a key it tells the user a key is needed instead of erroring.

## Plans & payments

Four tiers wired in `lib/plans.js`: **Publisher $29/mo** (upload + auto-post only), **Creator $99/mo** (30 faceless videos/mo), **Studio $119/mo** (both, 60 videos), **Autopilot $100/mo** (3 videos/day auto-generated and auto-posted, zero clicks). New signups get a free trial (3 videos, 2 accounts).

Getting paid from Cameroon: **Paddle** (paddle.com) is the recommended processor — merchant of record, handles global tax, pays out via Payoneer which works with Cameroonian banks. Cameroonian/African customers can pay by card directly through Paddle/Flutterwave checkout — this is not a blocker. Create your subscription products there, paste the checkout links into `PAYMENT_LINK_*` in `.env.local`. (Manually set a paying user's plan for now — and grant that plan's credits, since there's no webhook yet: `UPDATE users SET plan='creator' WHERE email='...'` then in a Node/worker shell `grantPlanCredits(userId, 'creator')` from `lib/credits.js`, or just `UPDATE users SET credits = credits + 1650 WHERE email='...'`. Automate both with Paddle webhooks when you have volume.)

## Deploy (~$5-10/mo, two Railway services)

Railway: connect repo as **two services** from the same GitHub repo — one running `npm start` (web) and one running `npm run worker` (worker, background render/post loop). Both need:
- The same persistent **volume mounted at `/app/data`** (SQLite DB + all generated/uploaded media live here — Railway does not persist `public/` writes across redeploys, so media is served through `/api/media/...` instead of static hosting)
- Identical `WORKER_SECRET` value in both services (a mismatch here silently breaks the worker — the worker script logs an explicit 401 hint if this happens)
- `APP_URL` set to the full `https://...` domain (must include the scheme, or media fetches fail)
- `nixpacks.toml` with `[phases.setup] aptPkgs = ["ffmpeg"]` so FFmpeg is available at build time

SQLite is fine up to ~50 users; swap to Postgres beyond that.

## Unit economics

Faceless Studio video: ~$0.03-0.05 (Claude + OpenAI TTS; Pexels free), or add ElevenLabs cloning cost if using a cloned voice. Marketing/Creator Studio video: fal.ai cost scales with resolution × duration (see live estimate in-app, roughly $0.36–$3.90 for an 8-30s clip). A Creator customer at $99/mo using all 30 videos costs you ~$1.50 + hosting share. Margin on Faceless Studio ≈ 95%; Marketing/Creator Studio margin depends on your resale pricing vs. fal.ai's live rate, so price those per-generation or as a higher tier.
