# NicheCast

AI social media studio: three content engines (Faceless Studio, Marketing Studio, Creator Studio) that generate video, then auto-post everywhere — every post is AI-generated by design, no manual bulk-upload path. Includes an in-app AI assistant to help you use it all.

## Requirements

- Node.js 18+ (nodejs.org)
- **FFmpeg** — needed for video generation. On Mac: `brew install ffmpeg`

## Run it

```bash
npm install
cp .env.example .env.local
npm run dev        # app at http://localhost:3000
npm run worker     # 2nd terminal — renders videos + publishes due posts
```

Everything works with **zero API keys** (mock mode): silent voice track, generated gradient/slideshow visuals, template scripts, simulated posting. Add keys one by one in `.env.local` to go real. ## The three studios

**Faceless Studio** (`/dashboard/video`) — niche → trend research → AI script → voice-over (cloned voice if you've added one, else OpenAI TTS) → stock/AI visuals → burned-in subtitles → thumbnail → SEO pack → schedule. Up to 2 minutes. Choose **Generate & Post** or **Generate & Download only** per video.

**Marketing Studio** (`/dashboard/ads`) — real AI video ads via fal.ai. Three modes: standalone **product ad** from photos + template, **property/restaurant tour** (upload each room's photo, they're individually animated then stitched into one walkthrough), and **"make one like this"** (paste a reference video link, get an AI-video prompt inspired by its style, not a copy). Resolution 480p/720p/1080p and duration up to 30s, with a live cost estimate before you generate.

**Creator Studio** (`/dashboard/creator`) — upload a photo once to create a reusable **Character** (digital avatar), then generate that character in different scenarios (office desk, remote-work setup, walking down a street, etc.) from a prompt describing the action/mood. The same Character can be reused across future generations, including Marketing Studio ads. Note: this is photo-guided AI video generation, not lip-synced talking-avatar speech — that's a separate, pricier integration (HeyGen/D-ID-style) not built yet.

All three studios render in the background via the worker; pages show live per-step progress.

## Connecting social accounts (fully embedded)

Accounts page has a "Connect [platform]" button per platform — clicking it redirects straight to that
platform's own OAuth login (via Outstand), then back into the app with the account saved automatically.
Users never have to visit Outstand's dashboard or copy an ID by hand. This needs a one-time setup: create
an Outstand account, set `OUTSTAND_API_KEY` + `OUTSTAND_ORG_ID`, and add `{APP_URL}/api/accounts/callback`
as an allowed redirect URI in Outstand's dashboard settings. Bluesky (app password, no OAuth) and other
providers/mock-mode testing fall back to a manual-entry form, collapsed under "Manual entry" on the same page.

## AI content disclosure

TikTok/Meta now suppress reach on undisclosed AI-generated video. Every post — all of them are AI-generated now that Bulk Upload is removed — is flagged `ai_generated=1` and passed to the posting provider as a platform-native AI-disclosure field.

## AI assistant

A chat widget (bottom-right, all dashboard pages) answers "how do I..." questions about the app and can write ready-to-paste prompts for any studio. Runs on `ANTHROPIC_API_KEY`; without a key it tells the user a key is needed instead of erroring.

## Plans & payments

Four tiers wired in `lib/plans.js`: **Publisher $29/mo** (upload + auto-post only), **Creator $99/mo** (30 faceless videos/mo), **Studio $119/mo** (both, 60 videos), **Autopilot $100/mo** (3 videos/day auto-generated and auto-posted, zero clicks). New signups get a free trial (3 videos, 2 accounts).

Getting paid from Cameroon: **Paddle** (paddle.com) is the recommended processor — merchant of record, handles global tax, pays out via Payoneer which works with Cameroonian banks. Cameroonian/African customers can pay by card directly through Paddle/Flutterwave checkout — this is not a blocker. Create your subscription products there, paste the checkout links into `PAYMENT_LINK_*` in `.env.local`. (Manually set a paying user's plan for now: `UPDATE users SET plan='creator' WHERE email='...'` — automate with Paddle webhooks when you have volume.)

## Deploy (~$5-10/mo, two Railway services)

Railway: connect repo as **two services** from the same GitHub repo — one running `npm start` (web) and one running `npm run worker` (worker, background render/post loop). Both need:
- The same persistent **volume mounted at `/app/data`** (SQLite DB + all generated/uploaded media live here — Railway does not persist `public/` writes across redeploys, so media is served through `/api/media/...` instead of static hosting)
- Identical `WORKER_SECRET` value in both services (a mismatch here silently breaks the worker — the worker script logs an explicit 401 hint if this happens)
- `APP_URL` set to the full `https://...` domain (must include the scheme, or media fetches fail)
- `nixpacks.toml` with `[phases.setup] aptPkgs = ["ffmpeg"]` so FFmpeg is available at build time

SQLite is fine up to ~50 users; swap to Postgres beyond that.

## Architecture

```
app/dashboard/video/      Faceless Studio (wizard + live job progress)
app/dashboard/ads/        Marketing Studio (ad / property tour / "like this" modes)
app/dashboard/creator/    Creator Studio (characters + scenario generation)
app/dashboard/generate/   Caption generator (bonus)
app/dashboard/accounts/   Connected accounts (embedded OAuth connect) + voice cloning
app/dashboard/chat-widget.js   Floating AI assistant (all dashboard pages)
app/api/accounts/connect/  Starts the embedded OAuth "Connect account" flow (Outstand)
app/api/accounts/callback/ Receives the OAuth redirect back, saves the account
app/api/videos/           Faceless Studio jobs, ideas (trend research), schedule
app/api/ads/               Marketing Studio jobs incl. /similar (paste-a-link)
app/api/creator-videos/    Creator Studio jobs
app/api/characters/        Character (avatar) CRUD
app/api/voices/            Voice cloning CRUD
app/api/estimate-cost/     Live fal.ai cost preview
app/api/assistant/         AI chat assistant endpoint
app/api/worker/            renders all queued jobs + publishes due posts
lib/video/
  trends.js                Google Trends RSS + YouTube Data API
  script.js                Claude: ideas, scripts, SEO, visual keywords, "similar video" prompts
  tts.js                   ElevenLabs cloned voice | OpenAI TTS | silent mock
  voices.js                ElevenLabs voice cloning + speech synthesis
  visuals.js / images.js   Pexels stock | AI images | generated gradient slides
  falEngine.js             Shared fal.ai video engine (resolution tiers, cost estimate)
  ads.js                   Marketing Studio: single ad / property tour / similar-video generation
  creator.js                Creator Studio: character-driven scenario video generation
  assemble.js               FFmpeg: stitch, subtitles, thumbnail
  pipeline.js                Faceless Studio job orchestrator (step-by-step status)
lib/posting/                mock | outstand | postforme | blotato | ayrshare providers (swappable via POSTING_PROVIDER)
lib/plans.js                 tier limits + gating
lib/media.js                  Persistent-volume media storage + streaming route helpers
```

## Unit economics

Faceless Studio video: ~$0.03-0.05 (Claude + OpenAI TTS; Pexels free), or add ElevenLabs cloning cost if using a cloned voice. Marketing/Creator Studio video: fal.ai cost scales with resolution × duration (see live estimate in-app, roughly $0.36–$3.90 for an 8-30s clip). A Creator customer at $99/mo using all 30 videos costs you ~$1.50 + hosting share. Margin on Faceless Studio ≈ 95%; Marketing/Creator Studio margin depends on your resale pricing vs. fal.ai's live rate, so price those per-generation or as a higher tier.
